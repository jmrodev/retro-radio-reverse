[01] ALCANCE Y PRESERVACIÓN

Muchos transceptores legendarios de radioaficionado y comerciales de Yaesu / Vertex Standard, Motorola, Kenwood e Icom dependen de software de clonación de 16 bits para MS-DOS o Windows 3.1/95/XP para configurar canales, subtonos CTCSS/DCS y parámetros de PLL.


RetroRadio Reverse realiza ingeniería inversa a los binarios originales (.EXE) y al protocolo serie TTL para desarrollar herramientas de código abierto, multiplataforma y sin dependencias de sistemas operativos obsoletos.
