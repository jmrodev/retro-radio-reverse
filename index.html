RetroRadio Reverse

Preservación, ingeniería inversa y herramientas modernas para transceptores clásicos y software de radio de la era DOS / Win32.

Ver Repositorio en GitHub Equipos Soportados

🎯 Propósito del Proyecto

Muchos transceptores de radioaficionado y comerciales de marcas como Yaesu/Vertex, Motorola, Kenwood e Icom dependen de programas obsoletos de 16 bits (DOS / Windows 95/XP) para grabar canales, frecuencias y subtonos CTCSS/DCS.


Este proyecto se dedica a:

  • Desarmar y documentar los protocolos de comunicación serie y volcados de memoria EEPROM.
  • Desarrollar retrorig: software multiplataforma moderno en Python para leer y programar sin necesidad de DOSBox o PCs antiguas.
  • Preservar el conocimiento técnico y esquemas de cableado CAT/clonado.

⚡ Software: retrorig

CLI moderno en desarrollo para interactuar directamente con los equipos:

# Clonar dump de memoria desde la radio
retrorig read ftl2011 /dev/ttyUSB0 -o backup.bin

# Exportar lista de canales a formato editable (CSV)
retrorig dump backup.bin -o canales.csv

# Control CAT en vivo para equipos HF (FT-747GX)
retrorig cat ft747 /dev/ttyUSB0 --freq 7100000 --mode lsb
